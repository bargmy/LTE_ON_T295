# LTE_ON_T295

Get the SIM card working on the Samsung Galaxy Tab A 8.0 (2019, SM-T295) running LineageOS 22.2.

## Works

- Calls
- Internet
- SMS
- Call audio
- SIM card settings

## Requirements

- Galaxy Tab A 8.0 2019 (SM-T295, SIM model)
- LineageOS 22.2
- Magisk

## Steps

1. Download the module
2. Install and reboot
3. For internet to work, go to SIM card settings and manually put your APN
